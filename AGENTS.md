# Agent instructions

This repo collects GRAIL hackathon submissions.

- To submit or update a team's project, follow [skills/grail-hackathon-submit/SKILL.md](skills/grail-hackathon-submit/SKILL.md).
- A submission may only change files inside `submissions/<event>/<team-slug>/`. Never edit other teams' folders, files at the repo root, `.github/`, or `scripts/`.
- Before opening a pull request, run `python3 scripts/validate_submission.py submissions/<event>/<team-slug>` and fix every error.
